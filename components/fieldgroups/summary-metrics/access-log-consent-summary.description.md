Data-collection consent dimension for aggregated access-log summary records, so consented vs non-consented traffic can be broken down via GROUP BY.
Reuses the Adobe consent standard at the standard xdm:consents.xdm:collect path; the choice value uses the standard vocabulary (y opt-in, n opt-out, p pending, u unknown, dy default opt-in, dn default opt-out). The dy/dn values represent the customer's configured default consent, applied to requests that carry no explicit consent signal (CMP or WebSDK opt-out cookie), which lets defaulted-in traffic be distinguished from explicitly consented traffic.
